========================================================================
ENVIRONMENT LIFECYCLE & RELEASE PROMOTION PIPELINE
========================================================================

1. Tier 1 - Development (`01_Source_Code/`):
   - All active code changes, new feature additions, and bug fixes occur here.
   - Connected to the local or development database via `01_Source_Code/db_config.json`.
   - Verified via local execution: `python desktop_app.py` or `build.bat`.

2. Tier 2 - User Acceptance Testing (`02_UAT/`):
   - Code verified in `01_Source_Code/` is promoted to `02_UAT/`.
   - Connected to the staging database via `02_UAT/db_config.json`.
   - QC supervisors and plant technicians test the build on test helmets and workstations.
   - Any bugs identified during UAT are resolved, re-tested, and back-ported to `01_Source_Code/`.

3. Tier 3 - Live Production (`03_Production/`):
   - Once the UAT testing phase is fully signed off, the release is promoted to `03_Production/`.
   - `build.bat` and `studds_installer.iss` generate the final production installer.
   - CRITICAL: Never overwrite `03_Production/db_config.json` during file synchronization.

========================================================================
COMPILATION & PACKAGING INSTRUCTIONS
========================================================================

Step 1: Build the Standalone Executable
- Navigate to the active environment folder (`01_Source_Code` or `02_UAT`):
    cd 01_Source_Code
    build.bat
- This bundles Python, PyWebView, FastAPI, offline Vosk STT model, audio assets,
  and dependencies into `dist\StuddsQC.exe`.

Step 2: Build the No-Admin Setup Installer
- Open `studds_installer.iss` in Inno Setup Compiler.
- Click 'Compile' (or run `ISCC.exe studds_installer.iss`).
- Output installer is saved to `installer_output\StuddsQC_Setup_v1.0_NoAdmin.exe`.
- Distribute `StuddsQC_Setup_v1.0_NoAdmin.exe` to factory workstations (requires zero admin rights).
